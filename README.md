## 📖 简介 / About

**CF-Trace-Scan** 是一款专为中国移动网络优选设计的工具，旨在帮助用户快速找到低延迟、高速度的优选IP。本项目开箱即用，配置灵活。

---

## ✨ 主要特性 / Features

- 🚀 **极速测速**：支持多线程并发，秒级完成 IP 质量检测。
- 🎯 **精准筛选**：自定CIDR，精准匹配最适合你的网络环境。
- 💻 **跨平台支持**：支持 Windows / macOS。
- 🛠️ **简单易用**：友好的命令行/图形化界面，配置零门槛。

## 💡 快速使用 / Quick Start

1. 下载程序并解压。
2. 阅读README文件（如有需要）。
3. 运行主程序
4. 输入你需要过滤的IP/CIDR或者拖动iplist.txt到主程序上过滤AS13335的全段
